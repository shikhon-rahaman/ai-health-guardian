# AI Health Guardian 🫀

> AI-powered health risk detection web app — VoltHacks 2026

## What it does
Users enter their symptoms and vitals. The app uses Groq AI (LLaMA 3) to analyze the data and return an instant risk assessment with actionable health recommendations.

## Tech Stack
- Frontend: Next.js 14, Tailwind CSS, shadcn/ui
- Backend: Python, FastAPI, Groq API
- Database: Supabase (PostgreSQL)
- AI Model: LLaMA 3 70B via Groq

## Project Structure
ai-health-guardian/
├── backend/   → FastAPI Python backend
└── frontend/  → Next.js frontend
